# AGENTS.md

## Context

Ename is a public registry of verified human identifiers (format `<name>#<number>`) designed to last for centuries, operated by a non-profit association. To learn more about Ename, you can consult the document [Ename project synthesis](./docs/ename-synthesis.md). For internal technical implementation decisions of the registry (stack, hosting, schema), see [Ename technical synthesis](./docs/ename-tech.md).

1Place is the first operator of the Ename ecosystem, run by 1Place SASU, a company I manage alone, without partners or employees. To learn more about 1Place, you can consult the document [1Place project synthesis](./docs/1place-synthesis.md).
