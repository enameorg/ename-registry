# Architecture decision records

One file per technical decision that is hard to reverse, surprising without context, and the result of a real trade-off. [`docs/ename-internals.md`](../ename-internals.md) states the current rules and links to the ADR behind each one; this folder holds the why — context, rejected alternatives, consequences.

There is no index here: the file names are the list, and the internals are the index by topic. Conventions (when to write one, format, how to amend or supersede) live in [`docs/agents/domain.md`](../agents/domain.md).
